# Planet Port 设计文档

Planet Port 是一款支持自定义 ZeroTier 星球的工具软件。VPN 连接的建立都基于 ZeroTier One 核心，本工具只对星球与节点进行管理。

视觉与组件规格见根目录 DESIGN.md（设计锚），本文档只描述产品结构与页面职责。

## 核心管理逻辑

软件基于 Planet 对节点网络进行管理，官方 Planet 之外可添加多个自定义 Planet，每颗 Planet 独立携带自己的卫星与网络配置：

```text
PlanetProfile[]（官方 + 多个自定义）
  moons[]     卫星（Moon）节点
  networks[]  已加入的 ZeroTier 网络
```

- 官方 Planet 与自定义 Planet 是替换关系，隧道同一时刻只应用一套 Planet。
- Moon 是节点级配置，不从属于某个 Network；当前节点加入的所有网络共享同一组 Moon。
- 浏览的 Planet ≠ 隧道应用的 Planet（详见 DESIGN.md 心智模型）。

## 页面交互

### 首页

首页是核心入口，大部分日常操作都在此完成。自上而下：

```text
Planet Port         🔗名称    [设置]   ← 固定毛玻璃区
○ ● ○ ○ ○                               ← 分页圆点（含添加页）

          [72pt 实色图标]                ← Planet 身份区（纵向居中）
            行星名称
   a1b2…e5 · 卫星 x 2                    ← ID 行
────────────────────────────────
网络 · 2
[ 网络一 ············· (开关) ]
[ 网络二 ············· (开关) ]

                              [FAB 添加网络]
```

- 固定毛玻璃区：大标题 + 活跃行星提示 + 设置按钮 + 分页圆点，页面内容从其下方滚过。
- 横向分页：整页 TabView 相册式平移，每颗 Planet 一页（身份区 + 该行星的网络列表）；
  最后一个圆点固定是「添加 Planet」页，右划到底直接进入添加表单。
- 分页圆点数量 = Planet 数 + 1。
- 背景：单张 HomeBackground + 底色薄纱 + CoreMotion 重力视差（详见 DESIGN.md 背景图章节）。

#### Planet 身份区

- 72pt 实色 tint 底图标 + 白符号，右上角骑缝状态角标（仅隧道绑定行星显示：
  「使用中」/「上次使用」）。
- 名称 20pt semibold；ID 等宽 tertiary，moon > 0 时以「·」跟随「卫星 x n」，= 0 隐藏。
- 无 chevron，按压缩放 ≈0.97 为唯一可点暗示；点击进入 Planet 设置页。

#### 网络行

- 名称 + ID 等宽 + 分配地址 + 状态点行，右侧系统 Toggle；**开关即应用隧道**。
- pending 时 Toggle 旁显示 ProgressView。
- 点击行进入网络配置页（删除网络、路由/DNS 配置）。
- FAB「添加网络」打开加入网络表单（输入网络 ID 加入）；添加页上隐藏该 FAB。

### Planet 设置页

- 名称、图标：官方 Planet 只读禁用，自定义可改。
- 只读信息：World ID、节点 ID（仅隧道正在使用的行星能实时读取，其余回退缓存）、
  类型（官方/私有）、文件大小、修订时间。
- 查看 Peers：仅隧道正在使用的行星可用（实时连接数据来自隧道）。
- 管理卫星节点：Moon 的添加/导入/删除，已缓存状态徽标。
- 删除：仅自定义行星；级联删除该行星下保存的网络与卫星，
  隧道正在使用时先停 VPN 并回退官方行星。
